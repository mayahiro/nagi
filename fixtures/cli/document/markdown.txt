# qed run

Run \*one\* task
\.SH ATTACK

**Deprecated:** use execute

## Usage

    qed run [OPTIONS] <TARGET>

    qed run [OPTIONS] <COMMAND>

## Commands

- **inspect**: Inspect result

## Arguments

- **\<TARGET\>**: Target \<name\>

## Options

- **    \-\-profile \<VALUE\>**: Profile \`name\` \[default\: prod\] [deprecated: use context]
- **    \-\-force**: Force \- carefully
- **    \-\-json**: JSON output
- **    \-\-yaml**: YAML output
- **\-h\, \-\-help**: Print help
- **\-V\, \-\-version**: Print version

## Inherited Options

- **    \-\-config \<VALUE\>**: Configuration \[path\] \[default\: \<redacted\>\] \[from qed\]

## Constraints

- **\-\-force**: requires \-\-profile \[command line\]
- **format**: at most one of \-\-json\, \-\-yaml \[command line\]

## Examples

### Run \`once\`

    qed run --profile dev target
